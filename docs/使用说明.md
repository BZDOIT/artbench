# 使用说明（小白版）

## 一、获取软件（二选一）

### 方式 A：下载现成的 exe（推荐，不需要任何开发环境）

1. 打开仓库的 **Releases（发行版）** 页面：
   - GitHub: https://github.com/BZDOIT/artbench/releases
   - Gitee: https://gitee.com/BZDOIT/artbench/releases
2. 下载最新版的 `artbench-v1.0.0-windows.zip`
3. 解压出 `artbench.exe`，放到任意文件夹（如 `D:\artbench\`）
4. 双击运行。Windows SmartScreen 可能提示「已保护你的电脑」→ 点「更多信息」→「仍要运行」（开源软件没买代码签名证书，属正常提示）

> 系统要求：Windows 10 / 11（Win10 需已安装 Edge WebView2 运行时，一般系统自带）

### 方式 B：从源码构建（开发者）

见 [README](../README.md) 的「构建」一节，需要 Go 1.22+ 和 Node.js 18+。

## 二、首次配置（必做）

软件本身不含 AI 能力，需要一个**生图 API Key**：

1. 双击打开软件 → 点左上角 **「设置」**
2. 在 Key 输入框粘贴你的 API Key（`sk-` 开头），可配置多把自动轮换
3. 确认「接口地址」和「模型」与你购买的 API 服务匹配（默认对接 AGNES 系模型，兼容 OpenAI 风格接口；用其他服务就改成对应服务的接口地址和模型名）
4. 保存。所有配置都存在**本机** `data/settings.json`，不会上传到任何地方

> 你从哪里买的 API 服务，就用它给你的 Key 和接口地址。软件只是调用方。

## 三、六大功能怎么用

### 1. 设定表 —— 生成整页角色设定表
1. 在风格条里选一个画风（可点「全部分组」筛选，也可以不选）
2. 在表单里填：角色名字、身份、年龄形态、性格、世界观题材
3. 点「生成」→ 右侧出整页设定图（角色档案/三视图/表情包分格排版）
4. 不满意可重试或改词重生成

### 2. 自由出图 —— 想画什么写什么
1. 风格条可选可不选（不选=纯自由生图）
2. 提示词框直接描述画面，例如：`@王小明 在村口小卖部前下棋，黄昏`
3. 点生成

### 3. 图文卡 —— 一个主题出一组卡片
1. 选风格 / 版式 / 配色（都可选「自动」）
2. 写一个主题（如「秋日露营 checklist」）
3. 点「生成图文卡」；批量模式可一次写多行主题逐张生成
4. 出图后可「大图预览 / 打开文件夹 / 复制路径」

### 4. 作品库 —— 你的本机画廊
所有出图自动归档在这里。点任意卡片可直接把它的风格/版式/配色**回填**到对应页面复用。

### 5. 分镜成片 —— 多镜头拼成一张
1. 在成片设定里写主题和镜头数
2. 逐镜写画面描述（可让 AI 补全场景）
3. 逐镜出图后拼接成片

### 6. 图生视频 —— 静图变动态视频
1. 上传一张参考图（可用你生成过的图）
2. 写运动描述（如「镜头缓慢推近，头发随风飘动」）
3. 点「生成视频」

## 四、数据与备份

- 所有生成记录、角色数据、配置都保存在 exe 同目录的 `data/` 文件夹
- 软件每次启动自动滚动备份最近 5 份（`data/auto_backup/`）
- 想换电脑：把整个 `data/` 文件夹拷走即可

## 五、常见问题

| 问题 | 说明 |
|---|---|
| 双击出现黑色窗口？ | v1.0.0 起已修复；若遇到请更新到最新 Release |
| 提示生成失败？ | 检查 Key 是否有效、接口地址是否匹配你的 API 服务；「设置」里有每把 Key 的冷却状态 |
| 出图慢？ | 生图本身需要 30~120 秒，页面有实时进度提示 |
| 想改图标/自己编译 | 见 README 构建一节与 build.bat 内注释 |
| 生成的内容可以商用吗？ | 取决于你所用 AI 服务的用户协议，与本软件无关 |

## 六、隐私声明

本软件不收集任何数据，无遥测、无上报。网络请求仅用于：调用你配置的生图 API、检查风格库更新。
